ALL ON RED! — LANDSCAPE MOBILE EDITION

Same gameplay, graphics, animations, missions, and cutscenes as Level 1 v0.9.

The one-file version can be opened locally by some mobile browsers, but iPhone's
Files preview frequently does not run local HTML as a normal interactive site.
For a reliable iPhone and Android experience, host this package on an HTTPS site.

QUICK DEPLOY (example: Netlify Drop)
1. Unzip this ZIP on a computer.
2. Upload the entire all_on_red_landscape_site folder to a static hosting service
   such as https://app.netlify.com/drop . The folder must contain index.html.
3. Open the public HTTPS link on iPhone or Android and rotate to landscape.
4. iPhone: disable Portrait Orientation Lock in Control Centre if necessary.
5. On iPhone, Safari Share > Add to Home Screen to install as an app-like icon.
   Android: Chrome menu > Install app or Add to Home Screen.

IMPORTANT: The web game does not become a native app-store app through this ZIP.
Android can auto-lock landscape if fullscreen/Screen Orientation API is supported.
iPhone Safari usually cannot auto-rotate or force landscape, so the game shows
an orientation prompt until you turn your phone sideways.

CONTROLS
On screen: directional arrows, CROC special, JUMP, KICK, PUNCH.
Keyboard: WASD/arrows, Space, Z, X, C.

No externally hosted scripts or assets are required once the files are served.
